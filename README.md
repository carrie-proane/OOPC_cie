# OOPC CIE Project

## Project Overview
This project is a console-based mystery simulation inspired by *And Then There Were None*.

## OOP Concepts Used
- Classes & Objects
- Encapsulation
- Inheritance
- Polymorphism
- Dynamic Memory
- File Handling
